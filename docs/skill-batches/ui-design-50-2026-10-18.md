# 排版、动态 UI 与图标：50 项补齐

日期：2026-10-18。用户确认添加上一轮列出的 50 项设计 Skill。T1 原有其中 35 项，本批只新增缺少的 15 个目录、来源及本说明；旧 Skill、CLAUDE.md、配置、共享链接和 ori 全部保持原样。

本机 Codex 新增 50 项；Claude 新增 48 项，原有 motion-design、game-interface-feedback 不覆盖。每个宿主最终都有清单中 50 个名称对应的 Skill 入口。全部任务前已有文件的哈希、修改时间、属性与链接经过前后比对保持不变。仅有本次新建的副本作兼容处理。

## 选择方法

做完整产品界面仍先选既有 designer-frontend-design / impeccable；新增 layout-and-spacing、visual-hierarchy、content-structure、responsive-design 用于具体版式学习和局部实现。ui-components / app-patterns / ux-flows 分别处理组件、应用外壳、用户流程；internationalization / accessibility 按实际范围补充。

已有 animate 用于实现动效，find-animation-opportunities 用于发现机会，review-animations 用于审查；新增 ui-animation 在需要弹簧、手势或录像测量时选用。SVG 静态图形用 svg-creator，简单 SVG 动效用 svg-animations，多状态角色/图标选 svg-character-animator，已有位图 Logo 需要矢量化和动效时选 pixel2motion。frontend-design-review 是新增的审查视角，不要求替换已有 design-review / ui-design-review，也不因安装而自动登录 Figma 或启动任何服务。

原生 iOS/Android 技能不能直接代替网页/FiveM NUI 实现。学习时要求解释设计理由、示范、练习和点评；这些 Skill 本身不是完整初学课程。只加载当前任务需要的部分。

## 兼容处理

Codex 新副本的过长描述已收窄；Claude 专用前置字段保存在 metadata，正文保留。review-animations 和 prototype 原有显式调用设置映射为 Codex agents/openai.yaml 的 allow_implicit_invocation=false。新 Claude 副本中三项过长描述也收窄，其他专用字段保留。Pixel2Motion 的 Codex UI 简介长度已调整。

SVG Creator 新副本追加本机说明：原 helper 写死 Linux 容器路径并会自动 pip 安装依赖，在 Windows 按说明选择可用渲染器和新输出目录，不直接运行容器命令。原辅助脚本未改、本批未执行。没有改 T1 已有 35 项的入口、正文或元数据。

## 验证范围

50 份 Codex 入口通过 quick_validate；50 份 Claude 入口检查 YAML、名称和描述长度。35 个 Python/JavaScript 文件通过语法检查；JSX 模板没有声称完成编译。两个宿主共核对 364 个本地 Markdown 引用；正则检测样本、代码和模板注释不当作文件链接。415 个选取的上游文件先按 blob 校验，再记录新增副本的适配差异。

本批没有运行 Skill 内的业务脚本、下载 Impeccable 引擎、启动浏览器/服务器、安装设计依赖、做真实页面/图标或验证视觉效果。CairoSVG、ffmpeg、Playwright、Python 图像/拟合依赖等仍按实际任务检查；源文件存在和语法通过不等于全部功能已验证。

# 先建立马来西亚项目依据

本文件是选择资料和检查配置的方法，不是 JKR、JPS 或 JUPEM 标准全文。核验资料记录见 [sources-and-learning.md](sources-and-learning.md)。

## 主管机关和依据表

先确认项目在半岛、Sabah 或 Sarawak 的具体位置、PBT、道路业主和排水审批机关。不要把一个州的做法自动当成全国要求。项目文件与主管机关要求冲突时列出冲突并交由项目负责人确认，不自行选择较宽松条件。

| 范围 | 应取得的项目依据 | 写入模型前要确认 |
|---|---|---|
| 道路几何 | JKR ATJ 或该道路主管机关正式采用文件，含版本/修订 | 道路类别、城乡环境、地形、设计速度、视距、曲线/缓和曲线、纵坡、超高、横断面、交叉口要求 |
| 路面/土方 | 项目规范、获批典型断面、地勘、材料与计量条款 | 各层厚度、formation/subgrade 的定义、表土/不适用料、边坡和处理范围、调整系数及其体积状态 |
| 雨水排水 | JPS/DID MSMA、地方要求及项目水文/水力设计依据 | 采用版本、汇水区、设计暴雨、ARI、IDF/雨型、允许排放、尾水、溢流路径、维护条件 |
| 测量/坐标 | 测量报告、控制点证书、项目采用的 JUPEM 或州测绘/土地部门资料 | 平面基准及 realization/epoch、投影/分区、单位、竖向基准、BM/TBM、坐标转换与独立检核 |
| 出图/报批 | 业主与 PBT 的提交清单、模板和签核程序 | 格式、图签、图幅、比例、单位、对象/文件命名、计算书与签核人 |

JKR 的 ATJ 8/86 (Pindaan 2015) 是本次检索发现的道路几何资料入口，不宣称它在所有项目上仍是最新或唯一适用文件。取得该项目获准使用的版本和表格再填设计值。本次未成功读取完整 JKR PDF，因此没有在技能中复制任何半径/超高/坡度表。

JPS 的官方 MSMA 页面确认第二版于 2012 年发布并于 2012-08-01 开始采用。页面不是完整计算手册；实际章节、补充通告和本地条件还需核验。网络资料混有不同版次，不能跨版次沿用章节编号或把“Chapter 13”一律当成同一主题。

## 坐标与高程的常见误判

- “马来西亚”不足以选择 EPSG、RSO 或 Cassini；“GDM2000”也不足以确定投影、realization 和转换参数。
- GDM2000、GDM2020、MRSO/BRSO、州 Cassini、旧基准、工程独立坐标都可能出现在项目资料中。这里只列需核实的标签，不给默认转换。国家或州控制要求以项目测量资料为准。
- 不因为一份较新的文件出现 GDM2020，就把旧项目全部重新贴成 GDM2020。设置 Drawing Coordinate System 不等于已正确完成点坐标的基准变换。
- 水平坐标系不能证明 Z 的基准。GNSS 椭球高、正高、海拔和工程约定 RL 不能互换；必须明确竖向控制与任何高程转换。
- 转换时记录输入/输出坐标系、方法、参数来源、覆盖范围和独立控制点残差。缺少这些信息先保留原始坐标。

## 设计参数台账

每个控制参数记录：`parameter / value / unit / applicability / source / edition / clause_or_table / review_status`。例如“某道路类别在某地形、某设计速度下的最小半径”是一条适用条件明确的记录，不能只记“半径 80”。

优先引用项目已提供或主管机关公开发布的原始资料。YouTube、培训课件、论坛和软件默认值用于学习操作；它们单独不能批准本项目参数。官方 PDF 下载失败、表格看不清或来源仅有搜索摘要时，写“未核验”，列出需取得的原文。

## 把依据落实到 Civil 3D

在项目副本中选择/创建 Metric DWT，检查 drawing/ambient units、图层、点格式、标签样式、站距格式和管材目录。Metric 只解决单位起点。

Alignment/Profile 的 Design Criteria File 和 Design Check Set 应与台账逐项对应；保留原始文件，生成有项目名/版本的副本。无法用 Civil 3D 内置表达式检查的 JKR 条件，明确列为外部/人工检查。不得只把 AASHTO XML 改名为 JKR。

收到 EU/UK 模板时可以复用不承载标准的版式，但必须清除或替换不适用的设计条件并核对单位；这不是把国外模板改名成马来西亚模板。若项目明确采用某个国际参考，记录马来西亚主管机关/项目的采用依据及限定范围，不能静默替代本地要求。

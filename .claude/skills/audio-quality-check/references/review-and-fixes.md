# 审查与修复边界

把文件可解码、指标符合合同、实际试听、游戏混音验收分开。耳机/扬声器与多人密集场景可能暴露单文件测量没有的问题；没有听过就报告未试听。

常见问题包括突变接点、削波/失真、噪声、DC、立体声抵消、时长/循环点偏移和音量层级错误。修复会改变内容：降噪可能产生金属感、限幅改变动态、去静音改变节奏、转单声道可能抵消声道。先以副本做小样并 A/B，原档不覆盖。

若用户要求归一化，先明确素材角色和目标，检查可用 two-pass 工作流及失败/回退说明；线性模式请求不保证素材都满足线性条件。输出采样率显式核对，因为 loudnorm 可能内部上采样；解码器或有损编码仍可能改变输出 true peak，需要对最终交付再测。

测试样本应覆盖正常、静音、接近满幅、极短、立体声、损坏输入与错误声道假设。记录真实值和容差来源，不把人为合成测试通过提升为真实车声好听或游戏可用。

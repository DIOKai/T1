# T1 本地音频接入

导入自 kajisho5/ffmpeg-skill，固定提交 11a70aa680c0916581164dc49957a1b64ec57a79，MIT。保留全部 Python runtime 脚本、运行模板、三份入口参考、MCP transport 和许可证；没有安装 npm wrapper、注册 MCP、安装字体/ASR 或改变宿主设置。优先直接运行已提供的 Python 脚本；Windows 使用实际 Python 可执行文件，不假定 python3 别名存在。

加载 Skill 不等于执行其全部功能。按任务选择工具，音频请求不触发视频导出、画面裁切、字幕生成、模型下载或 MCP 配置变更。缺外部二进制/可选依赖时报告具体未运行能力。可选转录引擎可能下载权重，不能自动启用。全部输入保留，ori 不写入；中间/输出文件放明确的新目录，不使用 --overwrite 替换用户旧文件。

原入口描述已收窄，正文追加本说明链接；其余上游复制文件逐字保留。原视频/社交平台 loudness 默认值不能当作 FiveM 引擎/环境音标准。输入要从实际 probe 和任务合同决定声道、采样率、编码与目标响度。测量模式不等于静默完成质量验收，试听另列是否已做。

特别注意：该版本 loop.py 要求视频流，而且不平滑重复接缝；它不是纯音频无缝循环制作器。请用独立 audio-loop-editing 技能处理相位、切点、交叉淡化和持续循环试听。其直接 FFmpeg 流程与本上游只使用自带脚本的工作流分开选择，不修改上游脚本来假装已有功能。

本批只用合成 WAV 测试相关音频路径，未验证全部视频、字幕、MCP、ASR 或 FiveM 功能。不要将源码语法通过、文档存在或单次 CLI 成功写成全套软件已验证。

实测参数：cut.py 的默认音频 stream-copy 按 packet 边界裁切，需要样本精度时使用 --accurate；join.py 默认使用交叉淡化，纯拼接应显式指定 --transition none。不要把默认输出时长假定为所请求裁切长度或两段长度之和。

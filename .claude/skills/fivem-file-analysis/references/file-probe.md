# 只读检查脚本合同

Python 标准库；一次显式文件，不递归、不解压、不执行、不下载、不写文件。使用方式：

```text
python scripts/inspect_file.py /absolute/input-file
```

JSON 输出到 stdout，若保存报告应选扫描输入以外的新文件，不能把输出重定向到输入或原档。脚本流式计算完整 SHA-256，只将前 4096 字节用于粗略识别，不输出正文/原始头字节。扩展名与候选内容类型分开。

结果区分标准 Lua 签名候选、可读 UTF-8 前缀、空文件、未知二进制；版本/format 字节只是提示，没有完整解析、语法验证或解密。format 字节只对 5.1–5.4 候选给提示；[Lua 5.0 头布局](https://www.lua.org/source/5.0/lundump.c.html) 不同，不能把端序字节标成 format。末尾 UTF-8 多字节跨采样边界可待续；若文件真的已结束则要求完整解码。NUL/非空白控制字节不会当作普通文本。UTF-16、压缩包、模型和任意未知数据不会据此判定加密。

拒绝最终路径的 symlink、Windows reparse 点和非普通文件。父目录链接仍可能存在；这不是对抗恶意并发替换的路径沙箱。要求稳定输入，检查打开文件身份和读取前后尺寸/mtime；读取失败、改变或明显身份不符返回错误，不输出成功哈希。相同尺寸/mtime 的对抗性改写不在检测保证内。

six_byte_prefix_truncated 只表示首六字节是否齐全，不表示完整 Lua 头部已经验证；完整格式始终未验证。退出 0 只表示读取和哈希完成，包括“格式未知”；退出 2 表示输入/读取错误。空文件能成功读取但不表示格式有效。原文件只读可能影响文件系统 atime，脚本不改内容、mtime 或权限。它不调用 Lua/Java、CodeWalker、Sollumz，也不解析 .fxap 授权或检查相邻资源，不能取代完整资源审查。
